# শুধু তোমার জন্য ❤️

This is the complete static website package. All photos are stored locally in `images/`, so the site does not depend on Google Drive or Imgur.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and the `images` folder (or upload the contents of this ZIP).
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`.
4. Save. GitHub will give you the website URL.
